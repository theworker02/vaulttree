# vaulttree

Vault timestamps and tree durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/vaulttree/

## Install / run

```bash
git clone https://github.com/theworker02/vaulttree.git
cd vaulttree
node src/cli.js
node --test
```
